Something gone wrong?

Send a private report to the development team. For game questions, ideas and conversation, join our Discord.

Please leave out passwords, Steam keys, payment details and personal documents. No attachments are collected.

Include this if you want us to be able to contact you. It is kept with your private report and is not displayed publicly.

Your report and optional contact details are stored for the development team to review and follow up. Sending does not post to Discord or create a public discussion.

Report received.

Keep this reference if you contact us again:

If you included an email, we can use it for follow-up. There is no automatic email confirmation.

A useful report includes

  • The steps that led to the issue.
  • What you expected to happen.
  • The error message, if there is one.
  • Your game build and system or browser.
